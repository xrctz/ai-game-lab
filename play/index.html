Run Locally

Copy these commands to clone and run any game on your own machine.

CraftVerse

git clone https://github.com/example/craftverse-engine
cd craftverse-engine
npm install && npm run dev

Requires Node.js 18+. Opens at localhost:5173.

DeadTakeover

git clone https://github.com/example/deadtakeover-protocol
cd deadtakeover-protocol
npm install && npm run dev

Requires Node.js 18+. Opens at localhost:5173.

Mindcraft

git clone https://github.com/example/mindcraft-control
cd mindcraft-control
docker compose up -d && npm run dev

Requires Docker & Node.js 18+. Opens at localhost:43110.
