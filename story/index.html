The philosophy

Why we build this way

This lab exists because AI is a capable collaborator — but only when you treat it like one.

What AI Co-Design Means Here

We do not use AI to "generate a game." Those outputs are shallow and break the moment you ask for something real. Instead, each project follows a loop:

  • Write the spec together — AI sketches algorithms, architecture, and edge cases
  • Implement incrementally — AI writes systems, not boilerplate; we review every commit
  • Iterate fast — the AI co-design loop lets you try three architectures before lunch
  • Ship it — every game on this hub plays in the browser with zero install

The result is not perfect. Some features are unfinished, some performance numbers could be better, and there will always be bugs. But the velocity is real — you can prototype an infinite world generator, a zombie FPS, and an AI agent launcher in the same month.

How to Use This Hub

  • Play panel — Select a game from the Play page and it launches inline. Use the controls to stop, fullscreen, or open a separate tab.
  • Theme remembers — Toggle light or dark mode. Your preference is stored and persists across visits.
  • Run on localhost — Each game has copy-paste dev commands on the Play page. Clone, install, and run in seconds.

What Comes Next

We are working on deeper AI integration inside each game: dynamic NPC dialog, real-time world adaptation, and procedural storytelling that actually responds to player action. The foundation — three working game engines — is enough to start experimenting seriously.

The goal is not a company. It is a pattern: prove that AI lets a small team build systems that used to require dozens of engineers. The lab itself is the proof.
