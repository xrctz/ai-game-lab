Origin log

Built by shipping games first

What exists, why it exists, and how the hub became a game library instead of a marketing folder dump.

01

Playable ideas

AI Game Lab is a front door for experiments that usually stay in folders: zombie FPS, squad shooter, voxel sandbox, racing, horror, RPG, and a local AI agent deck.

02

Games stay real

The theater loads actual static builds from /games. The shell can change completely without turning games into screenshots.

Make the hub feel like a game library — not a marketing landing page.
03

Fix visitor blockers

Earlier work fixed broken paths, caching, and pointer lock so Pages visitors get a working player.

04

Studio UI era

v19–21 was the pink glass “studio” hub — premium marketing layout with Outfit type and card grids.

05

Library OS (live)

Side rail navigation, acid lime system, full-bleed featured banner, horizontal game shelves, theater dock, and motion polish — the current public hub.

06

Cinematic shell

v25 adds constellation ambient, pointer spotlight, scroll progress, brand ticker, and carousel crossfades so the library feels like a polished game console storefront.
