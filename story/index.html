Story

Why we build this way.

This lab exists because AI is a capable collaborator — but only when you treat it like one.

Method

What AI co-design means here.

We don't use AI to "generate a game." Those outputs are shallow and break the moment you ask for something real. Instead, each project follows a loop.

  • Write the spec together. AI sketches algorithms, architecture, edge cases.
  • Implement incrementally. AI writes systems, not boilerplate — we review every commit.
  • Iterate fast. The co-design loop lets you try three architectures before lunch.
  • Ship it. Every game here runs in the browser with zero install.
The result isn't perfect. The velocity is.

You can prototype an infinite world generator, a zombie FPS, and an AI agent launcher in the same month. Some features are unfinished, some performance numbers could be better, and there will always be bugs. But the systems are real.

How to use this hub

Three things worth knowing.

  • Play panel. Pick a build from the Play page and it launches inline. Stop, fullscreen, focus, or open in a new tab — your choice.
  • Theme remembers. Toggle light or dark in the header. Your preference persists across visits.
  • Run on localhost. Every project has copy-paste dev commands on the Play page. Clone, install, run.
