Night of the Dead

Raylib + .NET zombie FPS with a Rust sim core. Needs a desktop build — not a browser iframe.

Open repo Back to theater
01

Why not embedded

OpenGL via Raylib + native Rust — cannot run in a hub iframe like the WebGL games.

02

Requirements

Ubuntu + GPU drivers and .NET SDK 10+. Source under the July 12 native folder in the repo.

03

Build & run

cd native/NightOfTheDead
dotnet run -c Release

dotnet publish -c Release -r linux-x64 --self-contained true -o ../../dist
./dist/NightOfTheDead
04

Controls

WASD · Shift sprint · mouse look · LMB shoot · R reload · Space jump · Esc pause.
