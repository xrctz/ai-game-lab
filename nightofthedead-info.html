Native desktop build

Night of the Dead runs locally.

A Raylib + .NET 10 zombie FPS with a Rust simulation core. GitHub Pages hosts the browser games—this one needs a desktop build on your machine.

Open AI Game Lab repo Back to player
01

Why it is not embedded

Night of the Dead uses OpenGL via Raylib and a native Rust sim library. It cannot run inside a browser iframe like the WebGL hub games.

02

Requirements

Ubuntu (X11/Wayland + GPU drivers) and the .NET SDK 10+. Source lives under July 12th new games to upload/3D Zombie Game/native/NightOfTheDead/ in the repo.

03

Build & run

cd native/NightOfTheDead
dotnet run -c Release

# Or publish a self-contained Linux build:
dotnet publish -c Release -r linux-x64 --self-contained true -o ../../dist
./dist/NightOfTheDead
04

Controls

WASD move · Shift sprint · Mouse look (pointer locked) · Left click shoot · R reload · Space jump · Esc pause.
